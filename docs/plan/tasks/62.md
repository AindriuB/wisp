## Goal
CI (`.github/workflows/ci.yml`) has failed on `ubuntu-latest` on every push
since 2026-10-30 (task 23). macOS passes. Make the `check` job pass on every OS
in its matrix. The first failure is a storage bug, not a test bug: storage ops
reject a reserved name only after a filesystem lookup. On a case-sensitive
filesystem that lookup fails first, so the caller gets `Io NotFound` instead
of `Invalid`. `cargo test` stops at the first failing crate, so the tests of
the later crates have never run on Linux. Any Linux-only failures they turn up
are part of this task.

## Context
- Latest failing run: 41591074798. `ops::tests::delete_refuses_dot_and_reserved_names_any_case` panics at crates/storage/src/ops.rs:1262. `delete_node(r, "Collection.toml")` returns `StorageError::Io` NotFound, not `Invalid`.
- crates/storage/src/ops.rs:161-192 — `clean_node`. `symlink_metadata(&abs)` at :173 runs before the name check at :182-189. The textual reserved checks must run before any filesystem access. They are: the first component starts with `.` or equals `environments`, and the file name is `collection.toml` or `folder.toml`, all compared case-insensitively. The `confine` check on the canonical path (:117-150) is still needed for symlinks and case aliases.
- The test also passes `.WISP` and `Environments`. These names do not exist on a case-sensitive filesystem, so they hit the same lookup. Check each path in the loop at :1253-1264, and every other `*_any_case` / `*reserved*` test in the file, against case-sensitive behaviour.
- Use the same case folding as `reserved_at_root` (crates/storage/src/ops.rs:241, test at :1481), not plain ASCII lowercasing, so the textual check and the wide-fold check agree.
- The implementer cannot run Linux locally. Iterate by pushing the branch, then running `gh run list --branch task/62-linux-ci --workflow ci.yml` and `gh run view <id> --log-failed`.
- Build with `CARGO_TARGET_DIR=/Users/Andrew/workspace/wisp/target/wt-62`.
